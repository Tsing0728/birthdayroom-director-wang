# 王导的生日小屋

一间可以走进去探索的互动生日小屋。礼物、贺卡和线索藏在家具里，集齐四份礼物后就能打开中央礼盒。

[打开试玩版](https://tsing0728.github.io/director-wang/)

## 本地运行

在仓库根目录运行以下命令，然后打开 [本地预览](http://127.0.0.1:8765/)。

```sh
python -m http.server 8765 --bind 127.0.0.1
```

## 操作

- 电脑：WASD 或方向键移动，拖动画面转向，按 E 或点击圆点互动。
- 手机：横屏后，拖动左下角的圆形摇杆移动，拖动画面转向，靠近物件后点击圆点互动。
- 靠近钢琴后，可以直接点黑白琴键。

## 文件

- `index.html`：入口、界面和样式。
- `room.js`、`scene.js`、`depth-renderer.js`：房间、物件和渲染。
- `game.js`、`effects.js`：礼物流程、操作和音效。
- 图片和音频与网页放在同一目录。素材来源见 [素材说明](素材说明.txt)。
